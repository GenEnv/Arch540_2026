# D team: the prompts

One run starts about 10 agents and takes 30 to 60 minutes. It can use up a Pro plan's 5-hour allowance. Watch the recorded run in the notes first.

For each step: copy the folder, open a terminal in the copy, run `claude`, paste the prompt.

## Step 1  The whole team

Folder: `team/`

```
Design the mixed-use block described in brief.md, working the way this project is set up. I want several genuinely different massing ideas, compared fairly with every rule checked, and one recommended scheme I can defend.
```
