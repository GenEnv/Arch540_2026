# A writing: the prompts

Each run takes under a minute. Everyone can run every step.

For each step: copy the folder, open a terminal in the copy, run `claude`, paste the prompt.

## Step 1a  Just ask

Folder: `step1_base/`

```
Read my design notes in this folder and write a 150-word project statement for the studio review panel. Save it in a file called statement. At the end, tell me the word count.
```

## Step 1b  Ask it to check itself

Folder: `step1_base/`

```
Read my design notes in this folder and write a 150-word project statement for the studio review panel. Save it in a file called statement. At the end, tell me the word count. Before you finish, check your own draft against my notes and the 150-word limit, and revise until it fits.
```

## Step 4   A reviewer

Folder: `step4_reviewer/`

```
Read my design notes in this folder and write a 150-word project statement for the studio review panel. Save it in a file called statement. At the end, tell me the word count. Use the method in rubric to write it. Then ask the reviewer to review the draft, giving it the name of the draft file. Revise using its comments. Do up to three rounds.
```

## Step 4   Harder: pass the excuse on
