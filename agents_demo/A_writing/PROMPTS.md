# A writing: the prompts

Each run takes under a minute. Everyone can run every step.

`complete/` has everything together: use it as the template for your own project.
`steps/` adds one thing at a time: use it to see what each file changes.

For each run: copy the folder, open a terminal in the copy, run `claude`, paste the prompt.

## The complete project

Folder: `complete/`

```
Read my design notes in this folder and write a 150-word project statement for the studio review panel. Save it in a file called statement. At the end, tell me the word count. Use the method in rubric to write it. There is a checker in the tools folder you can run. Then ask the reviewer to review the draft, giving it the name of the draft file. Revise using its comments. Do up to three rounds.
```
