# Project statement method

A project statement is read aloud to a review panel that has 30 seconds. Write it like this.

1. First sentence: the one design move, in plain words. What did you do to the building or site? Not the topic, not the programme.
2. One number per claim. Every claim about the project carries one figure from the notes (metres, units, storeys). No number that is not in the notes.
3. No adjective without evidence. "Vibrant", "innovative", "sustainable" are banned unless the next words show the measurable thing behind them.
4. Pick one idea. If the notes hold five ideas, keep the one that explains the others and drop the rest.
5. Facts must agree. If two places in the notes disagree, do not choose silently: say which one you used and flag it to the author.
6. Last sentence: one thing the panel should test or challenge.
7. Stay inside the word limit.
